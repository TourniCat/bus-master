# Planning Questions

Planning has intentionally been reset after locking the foundation.

The following should be redesigned from first principles instead of treating previous suggestions as final.

## Immediate next questions

### 1. What exactly is the player deciding before every mission?

We need the minimum set of decisions that creates meaningful variation with a fixed three-person team.

Candidate axes:

- weapon / attachment loadout
- armor / utility equipment
- consumables
- role emphasis
- tactical policy

Goal:

Preparation should be meaningful without turning into a long planning phase.

### 2. How much customization should each firearm support?

Need to decide:

- named real-world-like weapon categories vs fictional equivalents
- receiver / caliber abstraction
- optic
- muzzle
- magazine
- stock / grip
- underbarrel
- ammunition
- durability / maintenance, if any

Avoid complexity that exists only for gun-porn rather than affecting combat choices.

### 3. How should the three characters differ mechanically?

Need to decide whether differentiation comes from:

- base attributes
- growth rates
- weapon proficiencies
- perks
- unique specialties
- combinations of the above

Hard classes are currently disfavored.

### 4. What does progression feel like?

Need to determine:

- mission XP vs use-based skill growth
- downtime training
- perk acquisition
- equipment economy
- power curve
- campaign length

### 5. What is the mission / campaign structure?

PMM-like composition is desired, but details are open.

Questions:

- authored story missions + generated contracts?
- linear campaign or semi-open contract board?
- how often does story interrupt free contracts?
- what does calendar time change?
- fail-forward vs reload on mission failure?

### 6. How lethal should combat be?

Need to define:

- incapacitation
- permanent injury
- death
- recovery
- difficulty modes
- whether protagonist death is allowed in the default campaign

This directly affects character attachment.

### 7. How deep should relationships go?

Foundation is fixed, mechanics are not.

Need to decide:

- one pairwise closeness value or multiple dimensions
- authored vs systemic events
- romance availability
- jealousy / exclusion, if any
- group-level trio events
- story consequences

### 8. What should the camera let the player control?

PMM's automatic framing is a strong reference.

Need to decide:

- full manual pan/rotate/zoom
- temporary manual override
- character focus
- cinematic event cuts
- replay / slow motion

### 9. Engine and prototype strategy

Not decided yet for this reset.

Before implementing production systems, define the smallest playable proof:

> one map, three characters, one enemy group, one preparation screen, one automatic fight, one result screen.

The prototype should prove the combat loop before content scale increases.
